# 📖 Overview

Agentic AI Platform is a production-ready full-stack AI SaaS application that combines modern web technologies with AI-powered document processing and conversational intelligence.

The application allows users to:

- 🤖 Chat with AI
- 📄 Upload and analyze documents
- 🔐 Secure authentication
- 👤 User account management
- 🛡 Admin dashboard
- ☁ Cloud deployment
- 📱 Fully responsive interface

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/your-repository.git
```

```
cd your-repository
```

---

# Frontend

```
cd frontend
npm install
npm run dev
```

Runs on

```
http://localhost:3001
```

---

# Backend

```
cd backend
npm install
npm run dev
```

Runs on

```
http://localhost:5001
```
